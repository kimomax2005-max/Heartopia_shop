ANDROID + GITHUB + VERCEL QUICK GUIDE

1. Download and unzip this project on your Android phone.
2. Create a GitHub repository and upload the extracted files, preserving folders.
3. Create a Supabase project. Run supabase/schema.sql in SQL Editor.
4. Create your admin account in Supabase Authentication. Copy its user UUID and use it in supabase/make_admin.sql.
5. Import the GitHub repository into Vercel.
6. Add SUPABASE_URL, SUPABASE_ANON_KEY, SUPABASE_SERVICE_ROLE_KEY to Vercel Environment Variables.
7. Deploy/redeploy. Test the storefront, submit one test order, then sign in at /admin.html.
8. Test the admin status flow before accepting real customers.

Payment handling is manual only. The site does not connect to KBZPay/WavePay APIs and cannot automatically verify transfers. Only set status to "paid" after checking the transfer independently.
